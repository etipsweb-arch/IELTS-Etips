# IELTS-Etips (English Tips) - Platform Landing Page

Selamat datang! Proyek ini adalah purwarupa (prototype) tampilan web (landing page) untuk platform pembelajaran **IELTS-Etips (English Tips)** dengan konsep desain **Premium EdTech**.

Semua file web disimpan 100% secara lokal di komputer Anda tanpa di-deploy ke internet, hosting, ataupun domain eksternal.
